# UI Style Reference Moved

`docs/DESIGN.md` is the sole product UI source of truth for Eazy Review. It owns
the app-canonical tokens, typography, elevation, components, screen rules, and
design principles. `tailwind.config.js` is the configured token consumer.

The former Apple website analysis is preserved as non-authoritative research
at [`docs/research/apple-visual-analysis.md`](research/apple-visual-analysis.md).
Do not use its marketing layouts, desktop breakpoints, dark tiles, black
navigation, or 80px section rhythm as app requirements.

This pointer remains so historical links do not break. New product/UI work
should read `docs/DESIGN.md`, not this file.
